# Gridline F1 – Quick start

1. **Connect** the board to the computer with a USB data cable.
2. **Double-click** `install.bat` and choose `1`.
3. **Agree to the backup** (strongly recommended) and then to the install. Installing erases everything currently on the board.
4. **Calibrate** the touch screen: tap the center of 5 targets, then the test target.
5. **Set up Wi‑Fi** from your phone: join the `GRIDLINE-….` network with the password shown on the screen (or scan the QR code), and on the page that opens (`http://192.168.4.1`) pick your home network (2.4GHz) and enter its password.

That's it – the display runs on its own.

| File | What it does |
|---|---|
| `install.bat` | Install, back up, restore, update |
| `serial-monitor.bat` | View the board's log (for troubleshooting) |
| `verify-files.bat` | Check the firmware files without touching the board |
| `docs\GUIDE.html` | The full guide, including troubleshooting |
| `docs\VALIDATION.html` | What was tested and what still needs testing on the board |
| `preview\index.html` | Screenshots from the simulator |
| `SHA256SUMS.txt` | Checksums for all files |
