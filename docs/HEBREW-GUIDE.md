# Gridline F1 – מדריך התקנה ושימוש

Gridline F1 הוא קושחה חדשה ועצמאית שהופכת את לוח ה‑ESP32 עם מסך המגע (‏ESP32-2432S028) לתצוגת פורמולה 1 שולחנית. הלוח מתחבר ל‑Wi‑Fi בעצמו, מושך נתונים אמיתיים מ‑Jolpica‑F1 API ועובד בלי מחשב אחרי ההתקנה.

> פרויקט אישי לא רשמי. Formula 1 ו‑F1 הם סימנים מסחריים של Formula One Licensing B.V.

---

## 1. מה צריך לפני שמתחילים

| מה | פרטים |
|---|---|
| מחשב Windows | עם Python 3.12 שאפשר להפעיל כ‑`py -3.12` (כבר יש לך) |
| כבל USB לנתונים | כבל טעינה בלבד **לא** יעבוד. ללוח יש Micro‑USB וגם USB‑C – שניהם מתאימים |
| רשת Wi‑Fi של 2.4GHz | ה‑ESP32 **לא** תומך ב‑5GHz. ברוב הנתבים הביתיים יש גם רשת 2.4GHz |
| טלפון | להגדרת ה‑Wi‑Fi של התצוגה |
| כ‑15 דקות | כולל גיבוי מלא של הקושחה הקיימת |

### ⚠️ חשוב: מה יימחק

Gridline F1 הוא פרויקט חדש לגמרי עם מבנה זיכרון (partition table) משלו. ההתקנה **מוחקת את כל הזיכרון של הלוח**: הקושחה הקיימת, סיסמת ה‑Wi‑Fi שנשמרה בה, כיול המגע וכל ההגדרות. אי אפשר להעביר אותם – אחרי ההתקנה תכייל את המסך מחדש ותזין שוב את ה‑Wi‑Fi (כ‑2 דקות).

לכן תוכנת ההתקנה **מציעה גיבוי מלא** (4MB) של מה שיש היום על הלוח. מומלץ מאוד להסכים. עם הגיבוי אפשר תמיד לחזור בדיוק למצב הקודם.

## 2. התקנה – שלב אחר שלב

### שלב 1 – חילוץ הקובץ
1. לחץ קליק ימני על `Gridline-F1-v1.2.0-windows.zip` ← **Extract All** (חלץ הכל).
2. היכנס לתיקייה שנוצרה: `Gridline-F1-v1.2.0`.

> אל תפעיל את הקבצים מתוך ה‑ZIP בלי לחלץ – זה לא יעבוד.

### שלב 2 – חיבור הלוח
1. חבר את הלוח למחשב בכבל USB.
2. (בדיקה, לא חובה) פתח **Device Manager** ← **Ports (COM & LPT)**. אמור להופיע `USB-SERIAL CH340 (COMx)`. מספר ה‑COM יכול להשתנות – תוכנת ההתקנה מוצאת אותו לבד.

### שלב 3 – הפעלת ההתקנה
1. לחץ פעמיים על **`install.bat`**.
2. בפעם הראשונה בלבד יופיע `Preparing the installer` – התוכנה מכינה סביבת Python פרטית מהקבצים שבחבילה (בלי אינטרנט, כחצי דקה).

התוכנה כתובה באנגלית פשוטה (חלון ה‑CMD של Windows לא מציג עברית כראוי). הנה מה שתראה ומה לענות:

| מה מופיע במסך | מה לעשות |
|---|---|
| `What would you like to do?` | הקש `1` ואז Enter (Install Gridline F1) |
| `Checking firmware files` … `OK` | בדיקה אוטומטית של הקבצים (SHA‑256, גודל, מבנה). אם מופיע `FAILED` – הורד את החבילה מחדש |
| `Choose the display type and orientation` | הקש `1` ל**רוחב** או `2` ל**אורך** (שתיהן ST7789 – מתאימות ללוח שלך). אפשר לשנות אחר כך בהגדרות |
| `Found: COM5 (USB-SERIAL CH340)` `Use COM5?` | הקש Enter (כן) |
| `Board OK: classic ESP32, 4 MB flash` | הלוח זוהה בהצלחה |
| `Make a full backup … ? (Y/n)` | הקש Enter (כן). הגיבוי לוקח 2–6 דקות ונשמר בתיקייה `backups` |
| `Erase the board and install Gridline F1 now? (Y/n)` | הקש Enter (כן) |
| `Erasing the flash` ואז `Writing Gridline F1` | המתן. בסוף esptool מוודא את הכתיבה (hash) |
| `Open the serial monitor … ? (Y/n)` | Enter פותח חלון לוגים (לא חובה). סגירה: Ctrl+C |

אם בחרת לא לגבות, התוכנה תבקש להקליד `SKIP` באותיות גדולות – כל דבר אחר מבטל בלי לשנות כלום.

### שלב 4 – כיול מסך המגע (בהפעלה הראשונה)
1. על המסך יופיע `TOUCH CALIBRATION` עם מטרה (צלב בעיגול).
2. גע **במרכז** כל מטרה – רצוי עם ציפורן או עט פלסטיק (המסך הוא מסך מגע לחיצה, לא קיבולי). יש 5 מטרות.
3. בסוף מופיעה מטרת בדיקה (`CHECK`). גע בה. אם הדיוק טוב – יופיע `CALIBRATION SAVED`.
4. אם מופיע `NOT ACCURATE ENOUGH` או `CHECK FAILED` – התהליך מתחיל שוב אוטומטית.

### שלב 5 – הגדרת Wi‑Fi מהטלפון
אחרי הכיול התצוגה עוברת למסך `WI-FI SETUP` ומציגה:
- שם רשת זמנית, למשל `GRIDLINE-7F3A`
- סיסמה זמנית קריאה (בלי תווים מבלבלים כמו 0/O או 1/l), למשל `mx7k-p4ra`
- קוד QR

1. בטלפון: **הגדרות ← Wi‑Fi** ← התחבר לרשת `GRIDLINE-....` עם הסיסמה שעל המסך (או סרוק את קוד ה‑QR במצלמה).
2. בדרך כלל דף ההגדרה נפתח לבד. אם לא – פתח דפדפן וגלוש ל‑**`http://192.168.4.1`**.
3. בחר את רשת הבית מהרשימה (או הקלד את שמה), הזן את סיסמת ה‑Wi‑Fi ולחץ **Connect**.
4. אם הכל תקין: בטלפון יופיע `Connected!` ובתצוגה `Connected to … - restarting`. התצוגה מופעלת מחדש ומתחילה להוריד נתונים.
5. אם מופיע `Wrong password?` או `Network not found (is it 2.4 GHz?)` – תקן ונסה שוב. ייתכן שהטלפון יתנתק מרשת ה‑GRIDLINE בזמן הבדיקה; פשוט התחבר אליה שוב.

**הסיסמה של הבית נשמרת רק בזיכרון הלוח ולא נכתבת ללוגים.**

### שלב 6 – זהו!
מכאן התצוגה עובדת לבד. אפשר לחבר אותה למטען USB רגיל של טלפון.

## 3. השימוש היומיומי

### לרוחב או לאורך
יש שתי גרסאות קושחה, ושתיהן כוללות את אותם מסכים בדיוק:
- **לרוחב (Landscape, ‏320×240):** סרגל הלשוניות בתחתית, וההגדרות בסמל ☰ בפינה הימנית התחתונה.
- **לאורך (Portrait, ‏240×320):** הכותרת בשתי שורות (שם המסך וכפתור ☰ להגדרות למעלה, הסטטוס והשעה מתחת). הספירה לאחור בגריד 2×2 גדול, ובטבלאות מוצגות 10 שורות בעמוד עם חצי דפדוף בתחתית.

בכל רגע אפשר לעבור בין הכיוונים בלי מחשב: **Settings ← Orientation ← Wide / Tall** (נגיעה אחת). אם התמונה הפוכה ביחס לאיך שהלוח עומד, הפעל **Upside down**.


סרגל הניווט בתחתית המסך:

| לשונית | מה מוצג |
|---|---|
| **NEXT** | המרוץ הבא: שם, מסלול, מדינה, ספירה לאחור, תאריך ושעת הזינוק **בשעון ישראל**, והסשן הבא. נגיעה באזור הספירה מציגה את לוח הזמנים המלא של סוף השבוע |
| **DRIVERS** | טבלת הנהגים (מיקום, קוד, שם, קבוצה, נקודות). נגיעה בשורה מציעה לסמן נהג כמועדף |
| **TEAMS** | טבלת הקבוצות עם פס נקודות יחסי |
| **RESULTS** | תוצאות המרוץ האחרון כולל זמנים ופרישות (DNF/DSQ/DNS) |
| **CALENDAR** | לוח העונה. המרוץ הבא מסומן `NEXT`, מרוצים שהסתיימו עם ✓. נגיעה במרוץ מציגה את כל הסשנים |
| ☰ (סמל ימני; בלאורך – למעלה מימין) | הגדרות |

החצים ▲ ▼ בצד ימין מעבירים עמודים.

### מה אומרות הודעות הסטטוס (בפינה העליונה)

| הודעה | משמעות |
|---|---|
| `Updated 16:05` (נקודה ירוקה) | הנתונים הורדו מהאינטרנט בשעה הזו |
| `Cached · 16:05` (כתום) | מוצגים נתונים שמורים מהזיכרון (למשל אחרי הפעלה מחדש) – עדיין לא עודכנו |
| `Offline · 16:05` (אדום) | אין Wi‑Fi; מוצגים הנתונים האחרונים ששמורים |
| `Connecting` / `Syncing clock` / `Updating` | מתחבר / מסנכרן שעון / מוריד נתונים |
| `TLS error · …` | חיבור מאובטח נכשל (ראה פתרון בעיות) |
| `Rate limited` | השרת ביקש להאט; התצוגה תנסה שוב אוטומטית מאוחר יותר |
| `No data yet` | הנתונים עוד לא פורסמו (למשל לפני תחילת העונה) |

התצוגה **לעולם לא מחליפה נתונים טובים בנתונים פגומים**: אם הורדה נכשלה, הנתונים הקודמים נשארים ומסומנים בהתאם.

### כמה פעמים התצוגה מתעדכנת
- בין סופי שבוע: לוח העונה כל 6 שעות, טבלאות ותוצאות כל 3–6 שעות.
- בסוף שבוע מרוץ: כל שעה, ואחרי המרוץ כל 10 דקות עד שהתוצאות מתפרסמות.
- אחרי תקלה: ניסיון חוזר בהדרגה (30 שניות, דקה, 2, 5, 10… עד 30 דקות).
זה הרבה מתחת למגבלות השרת (500 בקשות לשעה).

### בין העונות
אחרי המרוץ האחרון מוצג `SEASON COMPLETE` עם האלוף (כשהטבלה הסופית זמינה) והודעה שלוח העונה הבאה עוד לא פורסם. ברגע שהוא מתפרסם – המרוץ הבא מופיע אוטומטית. בתחילת שנה, עד שיש נתונים לעונה החדשה, מוצגות הטבלאות הסופיות של העונה הקודמת (השנה רשומה בכותרת).

## 4. הגדרות (☰)

| הגדרה | הסבר |
|---|---|
| **Brightness** | בהירות המסך (– / +) |
| **Orientation** | כפתור כיוון המסך: **Wide** = לרוחב, **Tall** = לאורך. נגיעה אחת מחליפה מיד, וההגדרה נשמרת. כיול המגע נשאר תקף |
| **Upside down** | הופך את התמונה ב‑180° – לשימוש אם הלוח עומד הפוך |
| **Night dimming** | עמעום אוטומטי בלילה לפי שעון ישראל: שעת התחלה, שעת סיום ורמת בהירות לילה |
| **Accent** | צבע הדגשה (6 אפשרויות) |
| **Favorite driver** | נהג מועדף – מודגש בטבלאות ובמסך NEXT |
| **Wi-Fi** | פתיחת מסך הגדרת ה‑Wi‑Fi מחדש (למשל כשמחליפים נתב). הרשת הקיימת נשמרת עד שבוחרים חדשה |
| **Touch calibration** | כיול מגע מחדש |
| **Refresh data now** | רענון מיידי (פעם בדקה לכל היותר) |
| **About & diagnostics** | גרסה, Wi‑Fi, שעון, מצב כל מקור נתונים, זיכרון, ובדיקת TLS עצמית |
| **Restart display** | הפעלה מחדש |

ההגדרות נשמרות בזיכרון הלוח ונשמרות גם אחרי כיבוי. הכתיבה לזיכרון נעשית רק כשמשהו השתנה (כמה שניות אחרי השינוי האחרון) כדי לא לשחוק את הזיכרון.

### קיצורי דרך בלי מחשב
- **פתיחת הגדרת Wi‑Fi:** לחיצה ארוכה (3 שניות) על כפתור **BOOT** בלוח, בזמן שהתצוגה פועלת. כשמופיע `Release to open Wi-Fi setup` – שחרר.
- **כיול מגע מחדש כשהמגע לא מגיב:** גע במסך והחזק בזמן ההפעלה (כ‑3 שניות, עד שמופיע `Keep touching to recalibrate`).

## 5. פתרון בעיות

| בעיה | מה לעשות |
|---|---|
| `install.bat` אומר ש‑`py` לא נמצא | התקן Python 3.12 מ‑python.org וסמן "Add python.exe to PATH" |
| `No USB-SERIAL CH340 device was found` | 1) נסה כבל אחר (כבל נתונים). 2) נסה את השקע השני בלוח (Micro‑USB), או USB‑C עם כבל USB‑A ל‑C. 3) אם ב‑Device Manager אין CH340 – התקן את דרייבר CH340 של WCH (CH341SER) והפעל מחדש |
| `Failed to connect` / ההתקנה תקועה ב‑`Connecting...` | החזק את כפתור **BOOT**, לחץ ושחרר **RST**, שחרר את BOOT, והפעל שוב. התוכנה גם מנסה אוטומטית שוב במהירות נמוכה |
| המסך שחור אחרי ההתקנה | פתח `serial-monitor.bat` ובדוק שמופיעות שורות `BOOT`. אם יש לוגים אבל המסך כהה – נסה את גרסת ILI9341 (ראה סעיף 6) |
| צבעים הפוכים/מוזרים | ספר לי – זה אומר שהגדרת התצוגה צריכה כוונון |
| המגע לא מדויק | Settings ← Touch calibration, או החזק את המסך בזמן הפעלה |
| `Network not found` בהגדרת ה‑Wi‑Fi | ודא שזו רשת 2.4GHz ושהלוח קרוב לנתב |
| `TLS error` קבוע | בדוק ב‑About שהשעון `synced`. אם השעון תקין והשגיאה נמשכת – שמור לוג מ‑`serial-monitor.bat` ושלח לי |
| `Rate limited` | אין צורך לעשות כלום – ננסה שוב אוטומטית |

**לוגים:** `serial-monitor.bat` מציג את הלוג של הלוח (115200 baud) ושומר אותו בתיקייה `logs`. הלוג לא מכיל סיסמאות.

## 6. אפשרויות נוספות בתוכנת ההתקנה

| אפשרות בתפריט | מתי |
|---|---|
| `2) Backup only` | לשמור גיבוי בלי לשנות כלום |
| `3) Restore a backup` | לחזור לקושחה שהייתה לפני ההתקנה (מתוך התיקייה `backups`) |
| `4) Serial monitor` | צפייה בלוג |
| `5) Update application only` | עדכון גרסה עתידית של Gridline F1 **בלי** למחוק Wi‑Fi/כיול/הגדרות. עובד רק על לוח שכבר מריץ Gridline F1 – התוכנה בודקת את זה בעצמה |

**גרסת ILI9341:** בשלב בחירת סוג התצוגה הקש `3` (רוחב) או `4` (אורך). מיועדת ללוחות עם בקר ILI9341. לא נבדקה על הלוח שלך – השתמש בה רק אם ST7789 לא מציג תמונה.

**בדיקת קבצים בלבד:** `verify-files.bat` בודק את קבצי הקושחה (SHA‑256, גודל, מבנה) בלי לגעת בלוח.

### קבצי הקושחה (לשימוש ידני מתקדם)

| קובץ | כתובת | מתי |
|---|---|---|
| `ST7789_FULL-INSTALL_merged_write-at-0x0.bin` | `0x0` | התקנה מלאה (אחרי מחיקה), לרוחב |
| `ST7789_PORTRAIT_FULL-INSTALL_merged_write-at-0x0.bin` | `0x0` | התקנה מלאה, לאורך |
| `ST7789_APP-ONLY_update_write-at-0x10000.bin` | `0x10000` | עדכון אפליקציה בלבד, בלי מחיקה |
| `ST7789_part_bootloader_at-0x1000.bin` | `0x1000` | חלק מהקובץ המאוחד |
| `ST7789_part_partition-table_at-0x8000.bin` | `0x8000` | חלק מהקובץ המאוחד |

הגדרות פלאש: DIO, ‏40MHz, ‏4MB. סכומי ביקורת: `SHA256SUMS.txt`.

## 7. פרטיות ואבטחה (בקצרה)
- כל התקשורת לשרת הנתונים מוצפנת ב‑HTTPS עם בדיקת שרשרת תעודות ושם שרת, ובנוסף בדיקת תוקף התעודות מול שעון שסונכרן מהרשת. אין מעבר ל‑HTTP לא מאובטח.
- התצוגה לא מתחילה חיבור מאובטח לפני שהשעון סונכרן.
- הנתונים מגיעים מ‑Jolpica‑F1 API (חינמי, ללא מפתח, רישיון CC BY‑NC‑SA 4.0). אין שרת ביניים.
- מצב ההגדרה (Access Point) מוגן בסיסמה אקראית חדשה בכל פעם, ופעיל רק בזמן ההגדרה.
